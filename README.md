## 👋 Sobre mí

Construyo **SaaS y productos web end-to-end desde Chile**. Diseño, código, pagos, deploy, soporte — todo el ciclo. No colecciono tutoriales, envío features a usuarios reales que pagan.

- 🛠️ **Lo que hago:** Full-Stack · SaaS con IA · integraciones de pagos LATAM · apps móviles
- 🧠 **Stack preferido:** Next.js 16 + FastAPI + Supabase/Firebase + OpenAI
- 💳 **Pagos que ya integré:** MercadoPago (Chile), Flow.cl, próximamente Webpay
- 🌎 **Construyendo desde:** Chile 🇨🇱 para LATAM y Brasil
- 📬 **Contacto:** [soporte@cvlisto.cl](mailto:soporte@cvlisto.cl)
